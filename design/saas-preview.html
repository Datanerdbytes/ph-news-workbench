How a channel plugs in

One contract, many adapters

1
Authorize once per workspace

OAuth per platform. Tokens are encrypted and stored against the workspace, not the user, so teammates inherit access.

2
Adapt, don’t special-case the UI

Every channel implements the same publish, schedule, and insights interface. The composer renders fields from channel capabilities.

3
One queue, normalized metrics

The scheduler claims due posts and calls the adapter. Insights land in one metrics table with a channel column.
